┃ 4. TASK TYPE CLASSIFICATION                                                  ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

WEB_SEARCH
  Keywords: search, find, look up, query, web, internet, trending
  Example: "Search for Python tutorials"
  Handler: WebSearchClient
  Result: Title, URL, snippet

SYSTEM_MONITOR
  Keywords: cpu, memory, ram, usage, load, performance, health
  Example: "Check CPU usage"
  Handler: SystemMonitor.get_cpu_usage() + get_memory_usage()
  Result: CPU %, cores, memory %, used/total GB

HEALTH_REPORT
  Keywords: health, report, diagnostics, status
  Example: "Generate system health report"
  Handler: SystemMonitor.get_system_health()
  Result: CPU, memory, alerts, listening ports

PORT_CHECK
  Keywords: port, listening, connection, service
  Example: "Is port 8080 listening?"
  Handler: SystemMonitor.is_port_listening()
  Result: Port number, listening status

COMBINED
  Triggers: Multiple keywords from different categories
  Example: "Search for Docker and check system health"
  Handler: Multiple handlers executed sequentially
  Result: Web search + system monitoring combined

┃ 6. DESIGN PATTERNS IMPLEMENTED                                               ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Strategy Pattern
  → Different handlers per task type, registered at runtime
  → Enables adding new task types without modifying core

Context Pattern
  → AgentContext maintains state through execution pipeline
  → Enables passing data between components cleanly

Factory Pattern
  → create_hermes_agent_with_modules() pre-configures agent
  → Simplified instantiation for common use case

Builder Pattern (Implicit)
  → AgentContext built step-by-step during agent flow
  → Clean, readable construction of complex state

Observer Pattern (Implicit)
  → Task handlers "observe" and respond to task types
  → Loose coupling between router and executors

Adding a New Task Type:

  1. Add enum to TaskType:
     class TaskType(Enum):
         MY_NEW_TASK = "my_new_task"

  2. Add keywords to IntentClassifier:
     MY_KEYWORDS = {"keyword1", "keyword2"}
     if any(kw in input for kw in MY_KEYWORDS):
         task_type = TaskType.MY_NEW_TASK

  3. Create handler function:
     def handle_my_task(context, params):
         # Do work
         return TaskResult(...)

  4. Register handler:
     agent.register_handler(TaskType.MY_NEW_TASK, handle_my_task)

That's it! No core code modification needed.

  Input String → IntentClassifier → Intent Object

Intent Processing:
  Intent → HermesAgent._execute_tasks() → Task Routing

  Task Type → Handler Registry → Handler Function → TaskResult

Result Collection:
  TaskResult → AgentContext.add_result() → Results List

Response Formation:
  Results List → HermesExecutor._format_response() → Response Dict

Output Generation:
  Response Dict → HermesUI.display_response() → Formatted Output
