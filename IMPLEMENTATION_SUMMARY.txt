ARCHITECTURE INTEGRATION
================================================================================

5-Layer Hermes Architecture:
  Layer 1: UI (Telegram Webhook)
           ↓
  Layer 2: Result Formatting (TelegramClient)
           ↓
  Layer 3: Agent Orchestration (HermesAgent)
           ↓ [DEFENSIVE HANDLER INTEGRATES HERE]
  Layer 4: Intent Classification (CompositeIntentClassifier)
           ↓
  Layer 5: Modules/Security (URLSecurityHandler, SystemMonitor, etc.)

Integration Flow:
  User Message → InputSanitizer → DefensiveRouter → {
    CRITICAL: Reject with defensive message
    WARNING: Log and continue
    SAFE & LOCAL MATCH: Route to handler module (immediate response)
    SAFE & NO MATCH: Send to OpenRouter Llama LLM
  } → Add to Memory → Return Response
