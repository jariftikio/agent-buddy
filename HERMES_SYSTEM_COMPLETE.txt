RiskLevel (Enum):
├─ SAFE       → Standard domain, no indicators
├─ WARNING    → 1-4 indicators, manual review recommended
└─ CRITICAL   → Critical indicators (private IP, credentials, etc.)

URLIndicator (Enum):
├─ PUNYCODE           → xn-- prefix (IDN homograph attack)
├─ PERCENT_ENCODING   → %xx characters (obfuscation)
├─ UNICODE_CHARS      → Non-ASCII in hostname
├─ RAW_IP_ADDRESS     → 192.168.1.1 instead of domain
├─ PRIVATE_IP         → RFC1918 ranges (10.0.0.0/8, etc.)
├─ LOOPBACK_IP        → 127.0.0.1 or ::1
├─ SUSPICIOUS_DOMAIN  → Unusual patterns (regex)
├─ SUSPICIOUS_PORT    → Unexpected port for protocol
├─ EMBEDDED_CREDENTIALS → user:pass in URL
└─ LONG_DOMAIN        → >63 character hostname

URLAssessment:
├─ url: str
├─ risk_level: RiskLevel
├─ indicators: List[URLIndicator]
├─ confidence: float (0.0-1.0)
├─ reasoning: str
├─ recommendations: List[str]
└─ parsed_url: urllib.parse.ParseResult

SearchResult:
├─ title: str
├─ url: str
├─ snippet: str
├─ source: str ("serpapi" | "tavily")
└─ to_dict(): JSON format

CPUInfo:
├─ usage_percent: float
├─ count_logical: int
├─ count_physical: int
└─ to_dict(): JSON format

MemoryInfo:
├─ total_mb: float
├─ used_mb: float
├─ available_mb: float
├─ percent: float
└─ to_dict(): JSON format

┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

1. WEB SEARCH FLOW:
   User: "Search for Python async best practices"
     ↓
   Classify: WEB_SEARCH (0.9 confidence)
   Extract: search_query = "Python async best practices"
     ↓
   Handler: handle_web_search()
   Execute: WebSearchClient.search()
     ↓
   Format: TaskResult with results[]
     ↓
   Display: Formatted search results with source/snippet

2. SYSTEM MONITORING FLOW:
   User: "Check CPU and memory"
     ↓
   Classify: SYSTEM_MONITOR (0.9 confidence)
     ↓
   Handler: handle_system_monitor()
   Execute: SystemMonitor.get_cpu_usage() + get_memory_usage()
     ↓
   Format: TaskResult with cpu{} and memory{}
     ↓
   Display: Metrics with usage percentages

3. URL SECURITY FLOW:
   User: "Is https://suspicious.com safe?"
     ↓
   Classify: URL_CHECK (0.7 confidence)
   Extract: url = "https://suspicious.com"
     ↓
   Handler: handle_url_check()
   Execute: URLSecurityHandler.check_url()
     ├─ URLSecurityAnalyzer.assess()
     │  ├─ Check encoding
     │  ├─ Check IP address
     │  ├─ Check domain structure
     │  ├─ Check port verification
     │  └─ Check credentials
     └─ IndicatorDefanger.defang_url()
     ↓
   Format: TaskResult with risk_level, indicators, recommendations
     ↓
   Display: Risk assessment with defanged URL and recommendations

4. COMBINED FLOW:
   User: "Check system and search for optimization tips"
     ↓
   Classify: COMBINED (0.8 confidence)
     ↓
   Handler 1: handle_system_monitor()
   Handler 2: handle_web_search()
   Execute both in sequence
     ↓
   Format: TaskResult[] with all results
     ↓
   Display: System metrics + search results
