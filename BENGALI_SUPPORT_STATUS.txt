DATA FLOW:
  Bengali Input (e.g., "সিস্টেমের অবস্থা দেখাও")
         ↓
  Language Detection (LanguageDetector.detect_language())
  Result: Language.BENGALI
         ↓
  Intent Classification
  ├─ Keyword Path: Bengali keywords → TaskType
  └─ LLM Path: OpenRouter Llama → TaskType
         ↓
  Task Handler Execution
  (All handlers work with Bengali input unchanged)
         ↓
  UTF-8 Output Formatting
  (Bengali text → Terminal display)

LAYER INTEGRATION:
  Layer 5: HermesUI (Bengali output support)
  Layer 4: TaskResult (unchanged, supports Bengali data)
  Layer 3: HermesAgent (unchanged, language-agnostic)
  Layer 2: Intent Classification (Bengali keyword tiers added)
  Layer 1: Modules (unchanged, process Bengali queries as-is)
